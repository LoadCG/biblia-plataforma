# Fila de revisão editorial

Este índice organiza materiais preparados para revisão humana. Todos são
rascunhos, não fazem parte do catálogo publicado e devem ser avaliados antes de
qualquer integração em `core/content/dados`.

## Critério de saída

Cada item só pode avançar após primeira leitura registrada, segunda leitura
independente, resolução das pendências, validação das referências e decisão
explícita de aprovação. A rubrica está em [`../criterios-editoriais.md`](../criterios-editoriais.md).

`npm run check:revisao-editorial` confirma a governança documental; não substitui
avaliação humana nem aprova conteúdo.
